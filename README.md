# Sistema de Estudos — landing page psi.cacau

Landing page estática, responsiva e em português do Brasil para vender o template de Notion.

## Publicar

1. No arquivo `script.js`, substitua `KIWIFY_CHECKOUT_URL` pelo link do checkout do seu produto na Kiwify.
2. Abra a pasta no VS Code e use a extensão **Live Server** (ou abra `index.html`) para conferir localmente.
3. Crie um repositório no GitHub, envie estes arquivos e ative **Settings → Pages → Deploy from a branch → main / root**.

## Observação sobre venda internacional

A Kiwify aceita cartões estrangeiros e adapta o checkout para compradores de fora do Brasil, mas a cobrança é em reais; o banco do comprador faz a conversão. Portanto a página não promete preço em euro. Fonte: https://ajuda.kiwify.com.br/pt-br/article/o-checkout-funciona-fora-do-brasil-1cdb1ri/
